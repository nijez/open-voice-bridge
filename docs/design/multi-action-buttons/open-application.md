# 打开指定应用动作

## 交互与行为

普通键沿用当前动作菜单，在底部扩展动作区提供“打开指定应用…”，使用 macOS 原生文件选择器选取一个 `.app`。确认后自动保存，取消保留原配置；配置行显示“打开 应用名”，再次选择可更换目标。单击、双击和长按槽位复用同一入口。

触发时通过 Launch Services 启动或将已有进程切到前台。该动作属于一次性动作，长按不重复启动。应用找不到或系统打开失败时发出提示音并写入本地运行日志，其他遥控器动作继续工作。

## 实现边界

- `ButtonBinding.openApplication(ApplicationTarget)` 作为独立动作类型，继续使用已有 V3 配置和动作槽位；旧配置可由新版本读取。
- 目标保存应用路径、bundle identifier 和显示名称。优先使用用户选择的副本，路径失效后通过 bundle identifier 定位；路径已被其他应用占用时拒绝误开。
- `ApplicationLauncher` 负责目标解析和 `NSWorkspace.openApplication`，`KeyboardInjector` 仅接入现有 tap / hold 交付接口。hold 返回空保持 token，沿用现有一次性动作的生命周期。
- 选择器验证应用 bundle 和可执行文件；运行链路使用系统应用 API，支持路径中的空格和中文。
- 语音键继续沿用现有语音 / 快捷键配置入口。

## 验证

自动测试覆盖配置序列化、三个动作槽位重载、优先选择原副本、移动后重新定位、路径被其他应用占用、应用卸载、非法目标，以及单击 / 保持的一次性交付。测试通过注入解析及打开函数验证行为，不实际启动应用。

真机验收检查菜单与选择器、取消后保留原配置、选择后的名称显示、启动或聚焦目标应用，以及长按只执行一次。应用移动、卸载和启动失败等异常路径由自动测试覆盖，实际系统行为仍以目标 macOS 版本的验收为准。
